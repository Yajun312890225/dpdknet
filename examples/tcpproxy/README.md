# TCP Proxy Server Example

这是一个使用dpdknet库实现的TCP代理服务器，使用Forward函数进行双向数据转发。

## 功能

- 监听指定端口（默认8080）接收客户端连接
- 将客户端流量转发到目标服务器（默认43.136.168.109:8000）
- 支持双向数据转发
- 提供流量统计和连接时长统计
- 支持可选的数据加密（ENCRYPTYPE_MODEL）
- 支持命令行参数配置
- 支持多并发连接处理

## 文件说明

- `main.go`: 基础版本的代理服务器
- `main_advanced.go`: 高级版本，支持命令行参数和更详细的配置

## 使用方法

### 编译基础版本

```bash
go build -o tcpproxy main.go
```

### 编译高级版本

```bash
go build -o tcpproxy_advanced main_advanced.go
```

### 运行基础版本

```bash
# 使用默认参数（监听8080，转发到43.136.168.109:8000）
./tcpproxy

# 指定监听端口
./tcpproxy :9090

# 指定监听端口和目标服务器
./tcpproxy :8080 192.168.1.100:8000
```

### 运行高级版本

```bash
# 使用默认参数
./tcpproxy_advanced

# 完整参数示例
./tcpproxy_advanced \
  -listen :8080 \
  -target 43.136.168.109:8000 \
  -timeout 30s \
  -encrypt 0 \
  -buffer 10240 \
  -verbose true

# 参数说明
# -listen    监听地址，如 :8080 或 0.0.0.0:8080
# -target    目标服务器地址，如 192.168.1.100:8000
# -timeout   连接超时时间，如 30s、1m
# -encrypt   加密类型：0=无加密，1=MODEL加密
# -buffer    缓冲区大小，单位字节
# -verbose   是否启用详细日志
```

### 测试

可以使用tcpclient来测试代理服务器：

```bash
# 启动代理服务器
./tcpproxy :8080 43.136.168.109:8000

# 在另一个终端，启动客户端连接到代理服务器
cd ../tcpclient
./tcpclient localhost:8080
```

## 工作原理

1. 服务器监听指定端口等待客户端连接
2. 当客户端连接时，服务器自动连接到目标服务器
3. 启动两个goroutine分别处理：
   - 客户端→目标服务器的数据转发
   - 目标服务器→客户端的数据转发
4. 使用Forward函数进行实际的数据转发，支持超时控制和流量统计
5. 当任一方向的连接关闭时，整个代理会话结束

## 高级功能

### 连接管理
- 每个客户端连接都有唯一的连接ID
- 支持多个并发连接
- 自动管理连接生命周期

### 流量统计
- 实时统计双向流量
- 连接结束时显示总流量和连接时长
- 支持每用户流量统计

### 数据加密
- 支持MODEL加密算法
- 可通过命令行参数启用/禁用

### 配置灵活性
- 可配置缓冲区大小优化性能
- 可配置超时时间
- 可控制日志详细程度

## 性能优化建议

1. **缓冲区大小**: 根据网络环境调整`-buffer`参数，通常4KB-64KB之间
2. **超时时间**: 根据网络延迟调整`-timeout`参数
3. **日志级别**: 生产环境可设置`-verbose false`减少日志输出

## 注意事项

- 确保DPDK环境已正确配置
- 确保有足够的权限运行DPDK应用
- 代理服务器会为每个客户端连接创建一个到目标服务器的新连接
- 流量统计会在连接结束时打印到日志
- 使用加密功能时性能会有所下降

## 故障排除

1. **连接失败**: 检查目标服务器是否可达
2. **性能问题**: 尝试调整缓冲区大小
3. **超时问题**: 增加timeout参数值
4. **DPDK问题**: 确认DPDK环境配置正确
